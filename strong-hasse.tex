\begin{theorem}
Let $(V,q)$ be a quadratic space, then $V$ is isotropic as a vector space over $\mathbb{Q}$ if and only if $V$ is isotropic as a vector space over $\mathbb{R}$ and over $\mathbb{Q}_p$ for every prime $p$.\\
In other words, if $\dim{V}=n$, then $q(v)=0$ has a nontrivial solution in $\mathbb{Q}^n$ if and only if it has a nontrivial solution in $\mathbb{R}^n$ and in $\mathbb{Q}_p^n$ for every prime $p$.
\end{theorem}
\begin{proof}
The only if direction is trivial, since $\mathbb{Q}\subset\mathbb{R}$ and $\mathbb{Q}\subset\mathbb{Q}_p$ for every prime $p$ (the image of every $r\in\mathbb{Q}$ in the completion field is the equivalence class of the constant Cauchy sequence $r,r,\dots,r,\dots$), but the if direction is complicated and requires separate proofs for several cases of $n=\dim{V}$.\\
\section*{$n=2$}
Consider the quadratic form $q=a_1x_1^2+a_2x_2^2$, and assume that $a_1=1$ (otherwise divide $q$ by $a_1$, then any solution of $q$ is also a solution of $\frac{1}{a_1}q$).\\
If $v=(v_1,v_2)\in\mathbb{R}^2$, then $q(v)=v_1^2+a_2v_2^2=0\iff{a_2=-(\frac{v_1}{v_2}})^2$, thus $-a_2>0$ (because it is a square in $\mathbb{R}$), so we can reformat $q$ as $q=x_1^2-a_2x_2^2$, where $a_2>0$.\\
For every prime, $q(v)=0\iff{a_2=(\frac{v_1}{v_2})^2}$, thus $a_2$ is a square in $\mathbb{Q}_p$, but then $v_p(a_2)=v_p(r^2)=2v_p(r)$, where $r=\sqrt{a_2}$.\\ But \[a_2=\prod_pp^{v_p(a_2)}=\prod_pp^{2v_p(r)}=\prod_p\left(p^{v_p(r)}\right)^2\]
Thus $a_2$ is a square in $\mathbb{Q}$.
\section*{$n=3$}
Here $q=x_1^2-a_2x_2^2-a_3x_3^2$ (we assume that $a_1=1$ throughout this proof).\\
We assume that $a_2$ and $a_3$ are square free integers, otherwise we adjust $q$ so that $a_2$ and $a_3$ are square free, which means that for each prime $p$, the $p$-adic valuations $v_p(a_2),v_p(a_3)\in\{0,1\}$ ($1$ if $p$ is in the factorization, $0$ if it is not).\\
Without loss of generality we assume that $|a_2|\leq|a_3|$. Since $a_2$ and $a_3$ are integers, then their absolute values (either in $\mathbb{R}$ or $\mathbb{Q}_p$ for all $p$) are positive integers, thus their sum is a positive integer, and we denote $m=|a_2|+|a_3|\geq2$.\\
We start with $m=2$, that is $a_2=\pm1$ and $a_3=\pm1$, which means that \\$q=x_1^2\pm{x}_2^2\pm{x}_3^2$, but $q(v)=0$ over $\mathbb{R}$, so either of $a_2,a_3$ or both are $-1$, and it is immediate to find nonzero vectors $v=(v_1,v_2,v_3)\in\mathbb{Q}^3$ such that $q(v)=0$ (for instance, $q=x_1^2-x_2^2-x_3^2$, the vectors $(1,1,0)$ or $(1,0,1)$ are solutions in $\mathbb{Q}^3$).\\
Now assume that $m>2$, which means that $|a_3|\geq{2}$ (because we assumed that\\ $|a_3|\geq|a_2|$), but $a_3$ is a square free integer, thus, denote\\ $p'=p_1p_2\cdots{p}_{i-1}p_{i+1}p_{i+2}\cdots{p}_k$, we have that $a_3=\pm{p}_1p_2\cdots{p}_k=\pm{p_i}p'$, a finite product of distinct primes. Consider one of these primes $p_i$ where $1\leq{i}\leq{k}$, then there exists $v=(v_1,v_2,v_3)\in\mathbb{Q}_{p_i}^3$ such that $q(v)=v_1^2-a_2v_2^2-a_3v_3^2=0$ (because ($\mathbb{Q}_p^3,q)$ is isotropic for all primes $p$), which means that $v_1^2-a_2v_2^2=a_3v_3^2=p_ip'v_3^2\equiv0(\mod{p_i})$. We assume that $v$ is primitive, that is, the common divisor of $v_1,v_2,v_3$ is $1$, otherwise, there exists a common divisor $d>1$, so we can divide by it to obtain $u=\frac{v}{d}$, but $u_1^2-a_2u_2^2-a_3u_3^2=\frac{1}{d^2}(v_1^2-a_2v_2^2-a_3v_3^2)=0$ shows that the primitive vector $u$ is also a solution to $q(u)=0$.\\
Assume that $a_2\equiv0(\mod{p_i})$, that is $a_2=p_ia_2'$ for some $a_2'\in\mathbb{Z}_p$, then $a_2$ is trivially a square (of zero) modulo $p_i$ (because $0$ itself is in the equivalence class of $0(\mod{p_i}))$, thus we assume that $a_2\neq0(\mod{p_i})$.\\
We now look at $v_2$. Suppose that $v_2\equiv0(\mod{p_i})$, that is $v_2=p_iv_2'$ for some $v_2\in\mathbb{Z}_p$, then recalling that
$a_3v_3^2\equiv0(\mod{p_i})$, we have $v_1^2=a_2v_2^2+a_3v_3^2=a_2(p_ix)^2+p_ip'v_3^2\implies{p_i}|v_1^2\implies{p_i}|v_1$, because $p_i$ is prime, hence $v_1=p_iv_1'$ for some $v_1'\in\mathbb{Z}_p$, but then $a_3v_3^2=v_1^2-a_2v_2^2=(p_iv_1')^2-a_2(p_iv_2')^2\implies{p_i}^2|a_3v_3^2$, which means that $v_{p_i}(a_3v_3^2)=v_{p_i}(a_3)+v_{p_i}(v_3^2)=v_{p_i}(a_3)+2v_{p_i}(v_3)\geq2$, but $v_{p_i}(a_3)=1$ (because $a_3$ is square free), thus $v_{p_i}(v_3)\geq1\iff{p_i}|v_3$, thus $p_i$ is a common divisor of $v_1,v_2,v_3$, in contradiction to $(v_1,v_2,v_3)$ being primitive, from which we conclude that $v_2\not\equiv0(\mod{p}_i)\implies{v}_2\in\mathbb{Z}_p^{\ast}\implies{v}_2^2\in\mathbb{Z}_p^{\ast}$.\\
Recalling that $v_1^2-a_2v_2^2=p_ip'v_3^2\iff{a}_2v_2^2=v_1^2-p_ip'v_3^2$, but we saw that $v_2^2\in\mathbb{Z}_p^{\ast}\implies{a}_2=(v_2^2)^{-1}(v_1^2-p_ip'v_3^2)=(v_2^{-1})^2v_1^2-(v_2^{-1})^2p_ip'v_3^2\implies(v_2^{-1}v_1)^2=a_2+(v_2^{-1})^2p_ip'v_3^2\implies(v_2^{-1}v_1)^2\equiv{a}_2(\mod{p_i})$, thus $a_2$ is again a square modulo $p_i$.\\
By the Chinese Remainder Theorem we know that \[\sfrac{\mathbb{Z}}{a_3\mathbb{Z}}=\sfrac{\mathbb{Z}}{(p_1p_2\cdots{p}_k)\mathbb{Z}}\cong\prod_{j=1}^k\sfrac{\mathbb{Z}}{p_j\mathbb{Z}},\]
and since $a_2$ is a square modulo $p_i$ for every $1\leq{i}\leq{k}$, then $a_2$ is also a square modulo $a_3=p_1p_2\cdots{p}_k$, that is $z^2=a_2+a_3w$, for some $z,w$, that is $z^2\in\sfrac{\mathbb{Z}}{a_3\mathbb{Z}}\implies{v}_{p_i}(z^2)=2v_{p_i}(z)\geq{v}_{p_i}(a_3)$, which means that $|z|_{p_i}\leq\frac{|a_3|_{p_i}}{2}$.\\
We rearrange the equation above to $z^2-a_2=a_3w$, but then $a_3w$ is the norm on the field extension $K[\sqrt{a_2}]$ where $K=\mathbb{Q}$ or $K=\mathbb{Q}_p$.\\
If $w=0\iff{z}^2=a_2$, that is $a_2$ itself is a square, then any vector of the form $(v_1,\frac{v_1}{z},0)\in\mathbb{Q}^3$ is a solution of $q(v)$, because $v_1^2-(\frac{v_1}{v_2})^2v_2^2-0v_3^2=0$.\\
If $w\neq0$, then we claim the following:\\
There is a bijection between the set of rational solutions of $x_1^2-a_2x^2-a_3x_3^2=0$ and that of $x_1^2-a_2x_2^2-wx_3^2=0$.
\begin{proof}
Let $(v_1,v_2,v_3)$ be a solution to the equation with $x_3$, then we map $(v_1,v_2,v_3)\mapsto(a_2v_2+zv_1,zv_2+v_1,a_3v_3)$, and we check that $(a_2v_2+zv_1)^2-a_2(zv_2+v_1)^2-w(a_3v_3)^2=a_2^2v_2^2+2a_2v_2zv_1+z^2v_1^2-a_2z^2v_2^2-2a_2zv_2v_1-a_2v_1^2-wa_3^2v_3^2=(z^2-a_2)v_1^2-(z^2-a_2)a_2v_2^2-(wa_3)a_3v_3^2$, but $z^2-a_2=wa_3$, thus we get $(wa_3)v1^2-a_2(wa_3)v_2-a_3(wa_3)v_3^2$, that is $(wa_3v_1,wa_3v_2,wa_3v_3)$ which is the solution $(v_1,v_2,v_3)$ for the equation with $a_3$ that we started with (multiplied by a scalar), which means that $(a_2v_2+zv_1,zv_2+v_1,a_3v_3)$ is solution to the equation with $w$.
Now we map in the opposite way $(v_1,v_2,v_3)\mapsto(-a_2v_2+zv_1,zv_2-v_1,wv_3)$, and we calculate $(-a_2(zv_2+v_1)+z(a_2v_2+zv_1),z(zv_2+v_1)-(a_2v_2+zv_1),w(a_3v_3))=(-a_2zv_2-a_2v_1+za_2v_2+z^2v_1,z^2v_2+zv_1-a_2v_2-zv_1,(wa_3)v_3)=((z^2-a_2)v_1,(z^2-a_2)v_2,(wa_3)v_3)=((wa_3)v_1,(wa_3)v_2,(wa_3)v_3)$, thus we got the same solution for the equation with $a_3$ that we started with (multiplied by scalar), which means that the second map is the inverse of the first.\\
\end{proof}


then $|w|_{p_i}=|\frac{z^2-a_2}{a_3}|_{p_i}\leq|\frac{z^2}{a_3}|_{p_i}+|\frac{a_2}{a_3}|_{p_i}$, but we assumed that\\ $|z|_{p_i}\leq\frac{|a_3|_{p_i}}{2}$ and that $|a_2|_{p_i}\leq|a_3|_{p_i}$, hence $|\frac{z^2}{a_3}|_{p_i}+|\frac{a_2}{a_3}|_{p_i}\leq|\frac{1}{a_3}(\frac{a_3}{2})^2|_{p_i}+1=\frac{|a_3|_{p_i}}{4}+1$, but for any $a_3\geq2$, the inequality $\frac{|a_3|_{p_i}}{4}+1\leq|a_3|_{p_i}$ holds, thus $|w|_{p_i}\leq|a_3|_{p_i}$. 

But we assumed that there are rational solutions for every $m'<m=|a|+|b|$, that is, there are rational solutions for $x_1^2-a_2x_2^2-wx_3^2=0$, because $|a|+|w|<|a|+|b|=m$, thus, by the bijection above there exist rational solutions for $x_1^2-a_2x_2^2-a_3x_3^2=0$, which proves the induction.

\section*{$n=4$}
We have $q=a_1x_1^2+a_2x_2^2-a_3x_3^2-a_4x_4^2=a_1x_1^2+a_2x_2^2-(a_3x_3^2+a_4x_4^2)$, we have the following claim:\\

Let $q(v)=0$ in $\mathbb{Q}_p$ for every prime $p$, then there exists $a\in\mathbb{Q}_p$ such that $a_1x_1^2+a_2x_2^2=a$ and $a_3x_3^2+a_4x_4^2=a$.\begin{proof}
The proof is based on a set of corollaries of the basic lemma that every nontrivial isotropic subspace is the orthogonal sum $V=\mathbb{H}^m\perp{U}$, where $U$ is anisotropic and $m=2k$.\\
Consider a quadratic form $q$, where $n=\dim{q}$ is odd, if there exists some $u\in{V}$ such that $q(u)=a$ for some scalar $a\in{K}$, then let $U=Ku<V$ a one-dimensional subspace of $V$, and we construct a subspace $H<V$ by taking a complement to $U$, but then we take the quadratic form  $h=\langle1,-1,1,-1,\dots,1,-1\rangle$ on the $n-1$ basis elements of $H$, thus taking $(1,1,\dots,1)\in{K}^{n-1}$ yields zero, hence the quadratic form $q'=\langle1,-1,\dots,1,-1,a\rangle=h\perp{a}x_{n}^2$ yields $a$ for $(1,1,\dots,1,1)\in{K}^n$, and clearly the quadratic form $q''=q-ax_{n+1}^2$ yields zero for $(1,1,\dots,1,1,1)\in{K}^{n+1}$.\\
Suppose that we start from $q''$ and assume that there exists a $u$ such that $q''(u)=0$, then either $u=(u_1,u_2,\dots,u_n,0)$ such that $q(u_1,u_2,\dots,u_n)=0$, or $u=(u_1,u_2,\dots,u_n,1)$ such that $q(u_1,u_2,\dots,u_n)=a$, thus we get a circular reasoning:\\ $a$ is a value of $q$ $\implies$ $q\sim{h}\perp\langle{a}\rangle$ $\implies$ zero is a value of $q-ax_{n}^2$ $\implies$ $a$ is a value of $q$.\\
Now we assume there exist two quadratic forms $q_1,q_2$ of the same dimension, and we denote the quadratic form of the difference $q=q_1-q_2$. We saw that $a$ is a value of $q_1$ and of $q_1$ if and only if zero is a value of $q_1'=q_1-ax_n^2$ and of $q_2'=q_2-ax_n^2$.

We extend the quadratic form $q$ of the difference to be $q'=q_1\perp-q_2$, and extend the vectors $u$ and $w$ to be $u'=(u_1,u_2,\dots,u_n,0,0,\dots,0)$ and be $w'=(0,0,\dots,0,w_1,u_2,\dots,u_n)$, then if $v=u'+w'$, we have $q'(v)=q_1(u')-q_2(w')=a-a=0$. We observe that if $a=0$, then $q_1(u')=q_2(w')=0$ suggests that every nonzero element in $K$ is a value of $q_1$ and of $q_2$.
\end{proof}

Let $q=\sum_{i=1}^na_ix_i^2=q_1-q_2=a_1x_1^2+a_2x_2^2-(a_3x_3^2+a_4x_4^2+\cdots+a_nx_n^2)$, and we assume that the theorem is true for $n-1$ (we have the cases $n=2,3,4$ from above, for this assumption).\\
Suppose that $q(u)=0$ for $u=(u_1,u_2,u_3,u_4,\dots,u_n)\in\mathbb{Q}_p^n$, then there exists some $a\in\mathbb{Q}_p$ such that $q_1((u_1,u_2))=q_2((x_u,x_u,\dots,u_n))=a$.

Claim: $\mathbb{Q}_p^{\ast^2}$ is an open set in $\mathbb{Q}_p^{\ast}$

We use the theorem that $a\in\mathbb{Q}_p^{\ast^2}$ if and only if $a=p^nu$, where $n=2k$ is even and $u\in\mathbb{F}_p^{\ast}$, but then $v_p(p^nu)=n=2k$, thus, denote\\ $B(n)=\{b\in\mathbb{Q}_p^{\ast} : |b|_p\leq{p}^{-n}\}$ and $\partial{B}(n)=B(n)\setminus{B}(n-1)$, but $B(n)\setminus{B}(n-1)=B(n)\setminus{B}(n-1)^c=B(n)\setminus\{b\in\mathbb{Q}_p^{\ast} : |b|_p>n-1\}$, but we can circle every $b\in{B}(n-1)^c$ with an open environment (of the same or a smaller radius), thus $B(n-1)^c$ is open and the finite intersection $\partial{B}(n)=B(n)\setminus{B}(n-1)$ is open, but then $\{a\in\mathbb{Q}_p : a=p^{2k}u\}=\bigcup_{k=1}^{\infty}\partial{B}(2k)$ is an infinite union of open sets, thus open, and the intersection with $\mathbb{F}_p^{\ast}$ is also open.

Proposition: Let $a\in\mathbb{Z}_p$ then $a$ is invertible in $\mathbb{Z}_p$ if and only if $v_p(a)=1$.
\begin{proof}
Suppose $a$ has an inverse $b\in\mathbb{Z}_p$, then $v_p(ab)=v_p(a)+v_p(b)=v(1)=0$, but both $v_p(a),v_p(b)\geq0$, because they are in $\mathbb{Z}_p$, thus they must satisfy $v_p(a)=v_p(b)=0$. For the converse, suppose that $v_p(a)=0$, that is $a=a_0+a_1p+a_2p^2+\dots$, where $a_i\in[p-1]=\{1,2,\dots,p-1\}$, we construct $b=b_0+b_1p+b_2p^2+\dots$ where $b_i\in[p-1]$, such that $a_0b_0=1+p$, and $a_ib_i+1+1=p^{i+1}$, thus $ab=1+0p+0p^2+\dots=1$, and $v_p(b)=1$.
\end{proof}

Corollary: Let $a\in\mathbb{Z}_p^{\ast}$, then $a^2\in\mathbb{Z}_p^{\ast}$
\begin{proof}
$a\in\mathbb{Z}_p^{\ast}\iff{v}_p(a)=0\implies{v}_p(a^2)=2v_p(a)=0$.
\end{proof}
