\begin{theorem}
Let $(V,q)$ be a quadratic space, then $V$ is isotropic as a vector space over $\mathbb{Q}$ if and only if $V$ is isotropic as a vector space over $\mathbb{R}$ and over $\mathbb{Q}_p$ for every prime $p$.\\
In other words, if $\dim{V}=n$, then $q(v)=0$ has a nontrivial solution in $\mathbb{Q}^n$ if and only if it has a nontrivial solution in $\mathbb{R}^n$ and in $\mathbb{Q}_p^n$ for every prime $p$.
\end{theorem}
\begin{proof}
The only if direction is trivial, since $\mathbb{Q}\subset\mathbb{R}$ and $\mathbb{Q}\subset\mathbb{Q}_p$ for every prime $p$ (the image of every $r\in\mathbb{Q}$ in the completion field is the equivalence class of the constant Cauchy sequence $r,r,\dots,r,\dots$), but the if direction is complicated and requires separate proofs for several cases of $n=\dim{V}$.\\
\section*{$n=2$}
Consider the form $q=a_1x_1^2+a_2x_2^2$, and assume that $a_1=1$ (otherwise divide $q$ by $a_1$, which does not change the solutions to $q(v)=0$).\\
If $x_1,x_2\in\mathbb{R}$, then $q(v)=x_1^2+a_2x_2^2=0\iff{a_2=-(\frac{x_1}{x_2}})^2$, thus $-a_2>0$ (because it is a square in $\mathbb{R}$), so we can reformat $q$ as $q=x_1^2-a_2x_2^2$, where $a_2>0$.\\
For every prime, $q(v)=0\iff{a_2=(\frac{x_1}{x_2})^2}$, thus $a_2$ is a square in $\mathbb{Q}_p$, but then $v_p(a_2)=v_p(r^2)=2v_p(r)$, where $r=\sqrt{a_2}$.\\ But $a_2=\prod_pp^{v_p(a_2)}=\prod_pp^{2v_p(r)}=\prod_p(p^{v_p(r)})^2$, thus $a_2$ is a square in $\mathbb{Q}$.
\section*{$n=3$}
Here $q=x_1^2-a_2x_2^2-a_3x_3^2$ (we assume that $a_1=1$ throughout this proof).\\
We assume that $a_2$ and $a_3$ are square free integers, otherwise we adjust $q$ so that $a_2$ and $a_3$ are square free, which means that for each prime $p$, the $p$-adic valuations $v_p(a_2),v_p(a_3)\in\{0,1\}$ ($1$ if $p$ is in the factorization, $0$ if it is not).\\
Without loss of generality we assume that $|a_2|\leq|a_3|$. Since $a_2$ and $a_3$ are integers, then their absolute values (either in $\mathbb{R}$ or $\mathbb{Q}_p$ for all $p$) are positive integers, thus their sum is a positive integer, and we denote $m=|a_2|+|a_3|$.\\
Since $m\geq2$, we start with $m=2$, that is $a_2=\pm1$ and $a_3=\pm1$, which means that $q=x_1^2\pm{x}_2^2\pm{x}_3^2$, but $q(v)=0$ over $\mathbb{R}$, so either $a_2=-1$ or $a_3=-1$ (or $a_2=a_3=-1)$, but then $q(v)=0$ over $\mathbb{Q}$, considering, for instance, any Pythagorean triple (where the values of the triple are assigned differently to $x_1$, $\pm{x}_2$ and $\pm{x}_3$, according to their signs.\\
Now assume that $m>2$, which means that $|a_3|\geq{2}$, but $a_3$ is a square free integer, thus $a_3=\pm{p}_1p_2\cdots{p}_k$, a finite product of primes, where each prime can appear only once. Consider one of these primes $p_i$ where $1\leq{i}\leq{k}$, then there exists $v=(v_1,v_2,v_3)\in\mathbb{Q}_{p_i}^3$ such that $q(v)=v_1^2-a_2v_2^2-a_3v_3^2=0$ (because $\mathbb{Q}_p^3$ is isotropic for all prime $p$), which means that $v_1^2-a_2v_2^2=a_3v_3^2=p_i(p_1p_2\cdots{p}_{i-1}p_{i+1}p_{i+2}\cdots{p}_k)v_3^2\equiv0(\mod{p_i})$. We assume that $v$ is primitive, that is, the common divisor of $v_1,v_2,v_3$ is $1$, otherwise, there exists a common divisor $d>1$, so we can divide by it to obtain $u=\frac{v}{d}$, but $u_1^2-a_2u_2^2-a_3u_3^2=\frac{1}{d^2}(v_1^2-a_2v_2^2-a_3v_3^2)=0$ shows that the primitive vector $u$ is also a solution to $q(u)=0$.\\
We now look at $v_2$. Suppose that $v_2\equiv0(\mod{p_i})$, then recalling that \\
$v_3\equiv0(\mod_{p_i})$, we have $v_1^2=a_2v_2^2+a_3v_3^2=p_ix+p_iy$, for some integers $x,y$, thus $v_1^2=p_iz$ for some integer $z$, but if $p_iz$ is a square in $\mathbb{Z}_p$ then $p_iz=p_i^{2k}z'$, for some positive integer $k$ and $z'\in\mathbb{Z}_{p_i}^{\times}$ a $p_i$-adic unit, thus $v_1\equiv0(\mod{p}_i)$ and $v_1^2\equiv0(\mod{p}_i^2)$, but since we assumed that $v_2\equiv0(\mod{p}_i^2)$, then also $a_2v_2^2\equiv0(\mod{p}_i^2)$, thus $a_3v_3^2=v_1^2-a_3v_3^2\equiv0(\mod{p}_i^2)$, but we assumed that $v_p(a_2)\in\{0,1\}$, which means that $v_2\equiv0(\mod{p}_i)$, thus $p_i$ is a common divisor for $v_1$, $v_2$ and $v_3$, in contradiction to $(v_1,v_2,v_3)$ being primitive, from which we conclude that $v_2\not\equiv0(\mod{p}_i)$, and hence if $v_1^2-a_2v_2^2\equiv0(\mod{p}_i)$, that is, $a_2v_2^2$ is a square modulo $p_i$, then $a_2$ itself must be a square modulo $p_i$, that is, $x^2=a_2+p_iy$, for some $x,y$, but then $a_2$ is also a square modulo $a_3$, that is $z^2=a_2+a_3w$, for some $z,w$, that is $z^2\in\sfrac{\mathbb{Z}}{a_3\mathbb{Z}}\implies{v}_{p_i}(z^2)=2v_{p_i}(z)\geq{v}_{p_i}(a_3)$, which means that $|z|_{p_i}\leq\frac{|a_3|_{p_i}}{2}$.\\
We rearrange the equation above to $z^2-a_2=a_3w$, but then $a_3w$ is the norm on the field extension $K[\sqrt{a_3}]$ where $K=\mathbb{Q}$ or $K=\mathbb{Q}_p$.



\end{proof}
